# Sumit Kumar — Portfolio

Animated single-page portfolio built with plain HTML, CSS and JavaScript. Three.js (via CDN) powers the particle background. No build step.

- Palette: `#7C5CFF`, `#22D3EE`, `#F472B6` on `#0B1020`
- Images: picsum.photos placeholders
- Deploy: Render static site, publish directory `./`
